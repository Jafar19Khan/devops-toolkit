# Git Commands Reference

| Command | Purpose |
|---|---|
| `git init` | Initialize a local repository |
| `git clone <url>` | Copy a remote repository |
| `git status` | Show working-tree status |
| `git add <file>` | Stage a file |
| `git commit -m "message"` | Save a commit |
| `git branch` | List local branches |
| `git switch -c <branch>` | Create and switch to a branch |
| `git switch <branch>` | Switch branches |
| `git merge <branch>` | Merge a branch |
| `git fetch` | Download remote references |
| `git pull` | Fetch and integrate remote changes |
| `git push -u origin <branch>` | Push a branch and set upstream |
| `git log --oneline --graph --all` | View compact commit history |
| `git tag -a v1.0.0 -m "Release"` | Create an annotated tag |
| `git push origin v1.0.0` | Push a tag |
