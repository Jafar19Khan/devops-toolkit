# Git Interview Questions and Answers

## 1. What is Git?
Git is a distributed version-control system that records changes to files and helps people collaborate on software projects.

## 2. What is the difference between merge and rebase?
Merge combines histories and usually creates a merge commit. Rebase moves or replays commits on top of another base, creating a more linear history.

## 3. What is a pull request?
A pull request is a GitHub collaboration feature used to propose, review, discuss, and merge changes from one branch into another.

## 4. How do you resolve merge conflicts?
Fetch or pull the latest target branch, identify conflicted files, edit the conflict markers, test the result, stage the resolved files, and complete the merge or rebase.

## 5. What are Git tags?
Tags are named references to specific commits. Annotated tags include metadata and a message and are commonly used for releases.

## 6. What is Git workflow?
A Git workflow is an agreed process for branching, committing, reviewing, merging, and releasing code.

## 7. Explain git stash.
`git stash` temporarily saves uncommitted changes so the working tree can be cleaned or another branch checked out. `git stash pop` reapplies the saved changes.

## 8. What is the use of .gitignore?
`.gitignore` tells Git which untracked files and directories to ignore, such as build output, local settings, logs, and secrets.
